# 4. DualSense

Il DualSense (anche Edge) diventa uno o due Joy-Con, con giroscopio e accelerometro. Si collega via **USB** (consigliato) o Bluetooth. In Bluetooth l'app lo porta da sola in modalità estesa, quella con il giroscopio.

## Impostazioni

| Impostazione | Cosa fa |
|---|---|
| Interruttore | Attiva o mette in pausa il DualSense |
| **Si presenta come** | *Joy-Con 2* (un gamepad intero), *Joy-Con sinistro*, *Joy-Con destro*, *Coppia sx + dx* (due Joy-Con insieme) |
| **Nascondi il DualSense** | Lo "sequestra": gli altri programmi vedono solo il Joy-Con virtuale, non anche il DualSense (niente doppi comandi) |
| Vibrazione | Le vibrazioni chieste dal gioco arrivano ai motori del DualSense |
| Deadzone | Zona morta degli stick (0–25%, predefinita 6%) |
| Mappa tasti… | Una mappatura per ogni modalità |

La barra luminosa indica la modalità: blu = sinistro o Joy-Con 2, rosso = destro, viola = coppia.

## Mappatura predefinita

- **Coppia / Joy-Con 2**: per posizione, come un Pro Controller (Croce = B, Cerchio = A, Quadrato = Y, Triangolo = X, L1/R1 = L/R, L2/R2 = ZL/ZR, Create = −, Options = +, PS = Home, Touchpad = Cattura; con il Joy-Con 2 il tasto Microfono è C/chat).
- **Joy-Con singolo**: croce direzionale e tasti azione fanno la stessa cosa; i dorsali dell'altro lato diventano SL/SR; lo stick usato è quello mosso di più.

## Importa da JoyConFinto

Il pulsante in alto copia da JoyConFinto le mappature del DualSense, quelle dei Wii Remote (uscita Joy-Con classico) e la sensibilità del giroscopio.
